# FraudLens demo (deploy target)

A static page + one serverless function, wrapping the real trained model's output for a portfolio
demo. Not a production API — the ML model runs offline in `src/`; this folder only serves
precomputed predictions/SHAP values and makes one live Gemini API call per selection.

- `index.html` / `style.css` / `app.js` — the page. Loads `data/demo_transactions.json` (10 real
  transactions with real model probabilities and real SHAP drivers, generated by
  `scripts/export_demo_data.py`) and renders them.
- `api/explain.js` — Vercel serverless function (Node runtime). Takes one transaction's SHAP
  drivers and asks Gemini, live, for the plain-language write-up. Mirrors
  `src/explain_gemini.py`'s prompt design exactly.

## Deploying

1. In Vercel, import the `mahimarajesh7-netizen/fraudlens` repo, and set **Root Directory** to
   `web` (the Python training code lives outside this folder and Vercel should ignore it).
2. In the Vercel project's Settings → Environment Variables, add `GEMINI_API_KEY` with your key.
   Never commit this key to the repo.
3. Deploy. Framework preset should auto-detect as "Other" (static + serverless functions) — no
   build command needed.

## Regenerating the demo data

If you retrain the model, refresh the demo data too:

```bash
source .venv/bin/activate
python -m scripts.export_demo_data
```
